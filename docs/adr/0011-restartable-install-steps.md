# Host installation as restartable single-purpose steps

Installation is a sequence of `backfabric` subcommands (`keygen`, `sops add-host`, `probe`, `install`, `unlock`, `finalize`) instead of one script: each does one thing, never waits for a reboot, prints the next step, and can be re-run after a failure. `probe` boots the server into the NixOS installer (nixos-anywhere kexec phase) and writes the facter report before anything touches the disks, so hardware and configuration mismatches show up early; `install` refuses unless the report is committed. nixos-facter reports contain no MAC addresses, so the uplink MAC and its initrd driver are checked live on the installer, not by an evaluation assertion. nixos-anywhere disables host key checking itself, so the commands run it with an `ssh` shim that pins the Rescue host key.
