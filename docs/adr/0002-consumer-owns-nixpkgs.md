# NixOS stable, nixpkgs owned by the private repository

The flake tracks the current NixOS stable release (26.05), and the private repository owns nixpkgs (`backfabric.inputs.nixpkgs.follows = "nixpkgs"`), the same way this flake consumes disko and sops-nix. Security updates of nixpkgs then do not wait for a release of this repository. The cost: the modules and the `backfabric` command are built against the consumer's nixpkgs, which this repository's CI does not test; the k3s version will be pinned through a `package` option (with the k3s module, not implemented yet) so that a `nix flake update` never upgrades the cluster by accident (k3s minor versions must be upgraded one at a time).
